# 🏢 Система Управления Руководителя Направления (СУП SMB Offline)

Автономное кроссплатформенное корпоративное SPA-приложение для руководителя направления, работающее **без установки** и **без доступа в Интернет** в средах **Windows 10/11/Server** и **Astra Linux (Special / Common Edition)**, а также РЕД ОС и других отечественных ОС на базе Chromium.

Приложение размещается в общей сетевой папке (**SMB / NFS / Local Directory**) и открывается пользователями непосредственно через браузер.

---

## 🚀 Быстрый старт (Zero-Install / Без установки)

### 🪟 Windows (10 / 11 / Server)
1. Скопируйте папку с приложением на локальный диск или сетевой ресурс `\\SRV-CORP\DIR_DATA\`.
2. Запустите файл **`Запуск_СУП.bat`** (или **`Запуск_СУП_Фоновый.vbs`** для запуска без консольного окна).
3. Скрипт автоматически поднимает встроенный в Windows локальный микро-хост (`127.0.0.1:8080` через стандартный PowerShell), обеспечивая **Secure Context**.
4. Браузер открывается в отдельном окне и получает **полный нативный доступ к File System Access API** (`window.showDirectoryPicker()`) для чтения и записи реальных файлов в сетевой папке SMB.

### 🐧 Astra Linux / РЕД ОС / Linux
1. Распакуйте архив в целевую директорию или сетевую шару.
2. Сделайте скрипт исполняемым: `chmod +x start_sup_astra.sh`.
3. Запустите **`./start_sup_astra.sh`** или дважды кликните по ярлыку **`sup-director.desktop`** на рабочем столе.
4. Скрипт активирует защищенный локальный хост и откроет корпоративное окно через Chromium-ГОСТ / Astra Browser с разблокированным доступом к файловой системе.

## 🛠️ Архитектура и стек технологий

- **Стек ядра**: Чистый HTML5, CSS3 (переменные темы, светлая и тёмная темы), Vanilla JavaScript (ES2022+ модули).
- **Сетевое хранилище (Storage Engine)**:
  - **File System Access API** (`showDirectoryPicker`) с кэшированием дескриптора в **IndexedDB**.
  - **Пообъектная синхронизация JSON**: сущности хранятся в отдельных файлах (`task_*.json`, `contract_*.json`, `doc_*.json`, `employee_*.json`).
  - **Фоновый опрос (Polling 5 сек)** для совместной работы в реальном времени.
  - **Механизм блокировок (File Locking)**: временные файлы в `/data/locks/*.lock` с таймаутом 15 мин для предотвращения коллизий.
- **Оффлайн-библиотеки в `/vendor/`**:
  - `xlsx.full.min.js` (SheetJS) — парсинг и выгрузка Excel `.xlsx`/`.csv`.
  - `pizzip.min.js` + `docxtemplater.js` — генерация Word `.docx` по тегам.
  - `tesseract/` — **полноценные WASM-бинарники и модели** (`tesseract.min.js`, `worker.min.js`, `tesseract-core.wasm.js`, `rus.traineddata.gz`, `eng.traineddata.gz`) для оптического распознавания сканов без интернета.

## 📂 Структура каталогов данных (SMB Share)

При первом запуске приложение автоматически формирует в рабочей папке следующую структуру:
```text
/data/
├── tasks/           # Задачи канбан-доски (task_*.json)
├── employees/       # Штатный состав и справочник специалистов (emp_*.json)
├── contracts/       # Реестр контрагентов и договоров (cnt_*.json)
├── docs/            # Каталог отсканированных и распознанных документов (doc_*.json)
└── locks/           # Активные файловые блокировки редактирования (*.lock)
```

## 🧩 Функциональные модули комплекса

1. **📋 Канбан и оперативные задачи**:
   - Статусы: *«Бэклог»*, *«В работе»*, *«Согласование»*, *«Завершено»*.
   - Drag-and-Drop с автосохранением в JSON-файлы сетевой папки.
   - Слайдер и поле «% выполнения», чек-листы подзадач, приоритеты и фильтры.
2. **📅 Календарь и Недельный план**:
   - Режимы отображения: «Текущая неделя» (Пн-Вс) и «Месяц».
   - Автоматическая подсветка дедлайнов и красный бейдж *«Просрочено»*.
3. **📊 Диаграмма Ганта (MS Project Style)**:
   - Векторный рендер на чистом SVG без внешних библиотек.
   - Шкала «По дням» и «По неделям», двухслойные прогресс-бары готовности.
4. **📑 Документы и генератор Word (.docx)**:
   - Шаблоны: Акты сдачи-приемки, Договоры поставки, Доп. соглашения, пользовательские .docx.
   - Автоподстановка реквизитов из справочника и суммы прописью на русском языке.
5. **📷 Оффлайн OCR и Каталогизация**:
   - Распознавание произвольных сканов через локальный Tesseract.js WASM + модели `rus.traineddata.gz`.
   - Интеллектуальный RegEx-экстрактор (Тип, Номер, Дата, ИНН, КПП, Сумма, Контрагент).
   - Сохранение в каталог `/data/docs/` и выгрузка реестра в Excel.
6. **👥 Глобальный справочник**:
   - Двусторонний импорт и экспорт Excel (`.xlsx`/`.csv`) с автосопоставлением колонок.
7. **🧮 Корпоративные калькуляторы**:
   - Расчет НДС (20%, 10%, 0%) с быстрым копированием.
   - Калькулятор рабочих сроков (исключение сб/вс, прибавление +N рабочих дней).
   - Расчет ФОТ и себестоимости этапа.
   - Анализ освоенного объема (EVM: индексы SPI и CPI).

## 🤖 Настройка CI/CD и Авто-Релиз в GitHub

В репозиторий интегрирован пайплайн **GitHub Actions** (`.github/workflows/ci-cd-release.yml`), выполняющий:
1. **Проверку кода и линтинг** при каждом Push / PR в ветку `main`.
2. **Предзагрузку и валидацию всех бинарников Tesseract WASM и моделей**.
3. **Сборку и упаковку портативных пакетов**:
   - `SUP-Director-vX.X.X-Windows-Portable.zip`
   - `SUP-Director-vX.X.X-AstraLinux-Portable.tar.gz`
   - `SUP-Director-vX.X.X-SMB-NetworkShare.zip`
4. **Автоматическое создание GitHub Release** при создании Git-тега (например, `git tag v1.0.0 && git push origin v1.0.0`) или ручном запуске через `workflow_dispatch`.

### 📦 Локальная сборка релизных пакетов:
```bash
npm install
npm run package
```
Готовые архивы для всех платформ будут созданы в папке `/dist-releases/`.
